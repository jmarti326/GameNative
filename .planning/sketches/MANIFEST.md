# Sketch Manifest

## Design Direction

An effortless, native-feeling customization flow that stays out of the way until needed. It should preserve GameNative's dark Material 3 visual language, make visibility changes immediately understandable, support touch and controller input, and clearly distinguish hiding a navigation tab from removing a library source.

## Reference Points

- Mobile "Edit tabs" sheets with switches and reorder handles
- Existing GameNative library pill tabs, dark surfaces, and purple/cyan accents
- Material 3 bottom sheets, menus, switches, and settings rows
